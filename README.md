# DataNest

A lightweight Wikipedia-inspired search application built using **HTML, CSS, and JavaScript**. DataNest uses the **Wikipedia API** to search for articles and display relevant information in a clean interface.

## Features

* 🔎 Search for Wikipedia articles
* 📚 Fetch article information using the Wikipedia API
* 🖼️ Display article images
* 📄 Display article descriptions and content
* 🎨 Simple and responsive user interface
* ⚡ Built with vanilla JavaScript

## Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling and layout
* **JavaScript** — Application logic and API requests
* **Wikipedia API** — Article and search data

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/abhishek650-hx/datanest.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using **Live Server**.

4. Start searching for articles.

## API

DataNest uses the Wikipedia API to retrieve article and search information.
